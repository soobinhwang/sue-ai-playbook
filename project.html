Unordered List

Use bullet lists for non-sequential items, features, or observations:

  • First item: Description or detail about this point.
  • Second item: Another observation or feature worth noting.
  • Third item: Keep list items concise but informative.
  • Fourth item: Three to five items per list is usually ideal.

Ordered List

Use numbered lists when order matters — rankings, priorities, or sequences:

  1. First point — The most important or first-in-sequence item.
  2. Second point — Supporting detail or the next step in the sequence.
  3. Third point — Final item that wraps up the list.
